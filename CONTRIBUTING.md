# Contributing

Start from current `main` in a feature branch. Use a GitHub no-reply author email.
Keep credentials, runtime configuration, contacts, message text, logs and databases
out of commits. Use synthetic fixtures and add regression coverage for behavior changes.

Run the README validation commands before opening a pull request. Document platform
requirements and optional provider data flows. Keep external actions behind existing
identity, consent and review checks. The offline tests block unmocked socket connections.

This baseline replaces the prior public history. Existing contributors should clone
again or back up and selectively reapply reviewed changes; do not merge old history.
