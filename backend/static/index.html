Connect your calendars

Connections are set up privately on your Mac. Google calendars are read-only. Use the event editor for explicit iCloud changes.

Google: Create a Desktop OAuth client for the Google Calendar API, then sign in and choose which calendars to show.

iCloud: Use an Apple app-specific password, then choose which calendars to show. The event editor can create or update individual iCloud events when your account has permission.
